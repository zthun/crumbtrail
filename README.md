# Crumbtrail

File system utilities for Node.js, with interfaces that make file operations
easier to mock in unit tests.

## Packages

| Package                                                      | Description                                                                                     |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [@zthun/crumbtrail-fs](packages/crumbtrail-fs/README.md)     | File system searches, file watchers, a file repository, and file and folder read/write helpers. |
| [@zthun/crumbtrail-cli](packages/crumbtrail-cli/README.md)   | Command-line utilities for watching directory changes and refreshing directory listings.        |
| [@zthun/crumbtrail-nest](packages/crumbtrail-nest/README.md) | A NestJS module and injection token for the file system service.                                |
